# App generation

`spec-source-suite/` is reusable guidance; change it only for requested workflow/tooling work. Keep app inputs, code and evidence outside it.

Before planning, writing, changing or reviewing code (including tests and tooling), read and apply [guidelines.md](guidelines.md). Include its resolved path in delegated work; the suite's [engineering guidelines rules](spec-source-suite/AGENTS.md#engineering-guidelines) govern source resolution and handoff.

- Fresh work uses the current brief or selected bundle. Ordinary planners may consult [project memory](spec-source-suite/AGENTS.md#project-memory), without searching earlier tasks or conversations.
- Continuing work uses identified task paths or execution references. Resolve a bare task ID by immediate `.suite/tasks/` directory suffix; ask if absent, ambiguous, or continuation itself is unclear. Stop discovery when authority is resolved.
- Advice/tooling work uses requested files and relevant references, without task-history discovery.

For app work read the [shared rules](spec-source-suite/AGENTS.md) and your role routine. Use the selected [Markdown bundle](spec-source-suite/AGENTS.md#markdown-bundle); otherwise look outside the suite for its four file types and ask if multiple bundles are plausible. New authorized authoring uses `specs/` and the bundle templates. Missing required inputs block generation; no project intent yields NO_PROJECT.

Route document authoring to [Planner](spec-source-suite/PLANNER.md), and single-task implementation or app generation to [Supervisor](spec-source-suite/SUPERVISOR.md). The explicit suite skills are `spec-planner` and `spec-supervisor`. A direct implementation request authorizes derived plans and acceptance without routine reapproval. Preserve explicit requirements, approved text and historical records. [Records](spec-source-suite/AGENTS.md#records) describes task storage and recovery.

Only for requested automated-runner work read [RUNNER.md](spec-source-suite/RUNNER.md); its future-runner requirements are not app requirements. Suite guidance changes follow the requested scope, acceptance and [maintenance rules](spec-source-suite/AGENTS.md#workflow-maintenance).
