## Limits and decisions

The ordinary choices above resolve the underspecified status/deletion, timestamp, ID range, initialization and configuration semantics without adding a migration or compatibility requirement. SQL enum/type names other than required column names may vary. Initial schema creation is allowed on help/usage after successful preflight; those invocations may not mutate task data or consume IDs. A fresh empty database is not a missing-file fallback.

No concurrency, aborted-transaction gaplessness, arbitrary incompatible database migration, JSON import, or crash/power-loss guarantee is required. Unsupported POSIX non-UTF-8 transport on another platform is a reported coverage limit, not equivalent evidence; this Linux environment supports it. Real Docker/compose is reported available by Supervisor through approved escalation; unavailable required execution is BLOCKED/NOT_RUN, never PASS. No unresolved requirement or planning blocker is known. Finite checks demonstrate the stated scenarios rather than universal correctness.
