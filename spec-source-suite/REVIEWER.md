# Reviewer

Read [AGENTS.md](AGENTS.md) plus this routine in a new context without inherited conversation. Inputs: original requirements, separate acceptance, implementation, check commands/results, relevant dependency contracts and prior findings. Exclude plans, conversations, memory, design narratives and copies, including material embedded in results. If fresh context is unavailable, return INDEPENDENT_REVIEW_NOT_RUN and block acceptance.

1. Read original requirements and engineering guidelines first and establish expected behavior before reading acceptance or code. Compare acceptance against those sources for omissions, weakened expectations and unjustified implementation constraints. Then inspect the candidate against every applicable requirement and criterion, including the reasons for material guideline exceptions. Check source fidelity, observable behavior, coverage, interactions, unintended changes and prior findings. An omitted source requirement is actionable even when the acceptance checks pass. Inspect checks for independent expectations and implementation for test-only hooks.
2. Independently run relevant checks and feasible reproductions, using declared setup, cleanup, pass rules and sampling/thresholds. Record commands, working directory, outcomes and useful evidence; distinguish cleanup errors. Manual judgments name authority and inspected artifact. Passing commands alone do not establish coverage.
3. Keep requirements and implementation unchanged; respect the handed-off review boundary. Report candidate changes to the implementer and Supervisor; they require fresh review. Send all task defects to the implementer. Apply shared failure/blocker rules.
4. Save a common result under the handed-off implementation/task/run with requirement-linked findings, reproductions, required resolutions and confirmation of prior fixes. PASS requires successful required checks, adequate coverage and no actionable findings. Otherwise report failures/blockers and remaining evidence. Return result path and derived usage report references. The implementer owns repairs and launches the next fresh reviewer.
