# Reviewer

Read [AGENTS.md](AGENTS.md) plus this routine in a new context without inherited conversation. Inputs: original requirements, separate acceptance, implementation, check commands/results, relevant dependency contracts and prior findings. Exclude plans, conversations, memory and copies, including material embedded in results. If fresh context is unavailable, return INDEPENDENT_REVIEW_NOT_RUN and block acceptance.

1. Inspect the candidate against every applicable original requirement and acceptance criterion. Check source fidelity, observable behavior, coverage, interactions, unintended changes and prior findings. An omitted source requirement is actionable even when the acceptance checks pass. Inspect checks for independent expectations and implementation for test-only hooks.
2. Independently run relevant checks and feasible reproductions, using declared setup, cleanup, pass rules and sampling/thresholds. Record commands, working directory, outcomes and useful evidence; distinguish cleanup errors. Manual judgments name authority and inspected artifact. Passing commands alone do not establish coverage.
3. Keep requirements and implementation unchanged. Report planning/acceptance defects for return to the retained planner; implementation defects return to the implementer. Missing infrastructure is BLOCKED, skipped execution is NOT_RUN/BLOCKED, and observed behavioral failures remain FAIL. If the candidate changes during review, require review of the changed candidate.
4. Save a common result with requirement-linked findings, reproductions, required resolutions and confirmation of prior fixes. PASS requires successful required checks, adequate coverage and no actionable findings. Otherwise report failures/blockers and remaining evidence. Return result path and available session/turn references, without reading conversation logs for counters. The implementer owns repairs and launches the next fresh reviewer.
