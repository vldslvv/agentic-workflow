# Project memory

- Use `<project-root>/.agents/memory/index.md` and `entries/*.md`, outside the suite. Read the selected project's index and only relevant notes during ordinary planning and implementation. Missing memory means there are no notes yet.
- Keep index links with short retrieval hints. Notes contain useful lessons and source pointers in ordinary Markdown; no prescribed metadata is required. Current requirements and repository facts take precedence over advice. Check potentially stale advice against current sources without searching unrelated history.
- Pass relevant note paths to subsequent tasks. At completion or a blocked stop, add supported lessons, merge duplicates and correct stale advice. Initialize memory only for a useful lesson. Avoid transcripts, progress logs, speculation, secrets and copied configuration.
- Reviewers and all reconstruction workers, including planners, exclude project memory and its copies. Start reconstruction in a fresh allowed-input context if the current agent has already read excluded material.
