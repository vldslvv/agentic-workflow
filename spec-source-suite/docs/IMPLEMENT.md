# Implement — one ready task

Read [shared contract](SUITE_CONTRACT.md) once and this procedure. Input: complete approved plan/acceptance, authority/baseline and source identities, accepted dependencies, target, frozen checks and explicit owned/protected paths. Output: candidate, requirement-linked execution, fresh review and compact receipt.

## I1. Validate handoff

Resolve every required read path and identity from the role manifest. Confirm readiness under contract §§1–3 without loading the planner's procedure. Read the full approved plan and acceptance and relevant normative sources; record extra relevant inspection. Check protected digests without printing unchanged contents. Missing inputs block implementation.

Use selected notes only through retained handoff reads under [project memory](PROJECT_MEMORY.md#starting-and-retaining-inputs).

## I2. Implement and check

Build within owned paths, including authorized integration. Run the frozen requirement-linked public-interface tests, task checks and declared regression set once for this candidate/role under [contract §4](SUITE_CONTRACT.md#4-checks-and-repairs); add useful local tests for uncovered observable behavior. Use the recorded real dependencies or safe substitutes and keep production logic free of test-only exports/hooks. Preserve skipped/blocked test dispositions and exception evidence. Keep build executables outside retained source. Preserve commands/logs and source snapshot or revision/digest. Check protected identities and scope diff before review.

## I3. Spawn independent review

Spawn a reviewer with no inherited conversation using [REVIEWER](../prompts/REVIEWER.md). Supply an explicit read manifest with acceptance/normative sources, candidate/check identities, dependency evidence, raw results and reviewer-owned output; exclude plan/conversation. Reviewer performs independent execution and coverage assessment. Recheck candidate and protected identities after execution; moving-candidate results are invalid.

## I4. Repair or route

Follow contract §4. Keep this implementer's context for confirmed defects, preserve each attempt and return changed candidates to I2 and a new fresh reviewer at I3 until review reports zero unresolved actionable findings and all task acceptance gates pass, or an explicit stop applies. A stop with unmet gates leaves the task incomplete. Coverage reproductions go through planner validation and supervisor-authorized frozen additive revision. Route newly impractical tests with obstacle evidence to the supervisor for an autonomous testing-exception revision; resume affected checks against the authorized frozen revision without requesting user approval. Escalate other verifier/spec/infrastructure/plan issues with preserved evidence; do not edit protected inputs.

On a failed or blocked stop, apply [memory maintenance](PROJECT_MEMORY.md#completing-and-maintaining) to supported observations.

## I5. Integrate and return

Run declared real-dependency/regression checks for the integrated identity. Reuse this role's unchanged results only with scope/identity justification; integration changes affecting behavior require affected checks and fresh review. Return [receipt](../templates/RECEIPT.json) and [run report](../templates/RUN_REPORT.md) paths. The supervisor applies contract §5; final assembled-app checks remain a separate gate.

The completing agent applies [memory maintenance](PROJECT_MEMORY.md#completing-and-maintaining) within its declared memory write paths.
