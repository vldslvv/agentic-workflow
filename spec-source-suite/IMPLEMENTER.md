# Implementer

Read [AGENTS.md](AGENTS.md) plus this routine. Inputs: specifications, assigned task mode, relevant project state, accepted dependency contracts and ordinary memory; reconstruction uses only allowed inputs. Own the task from implementation through repairs, including planning for full mode.

1. Confirm implementation root, source task ID, assigned mode, scope, paths and accepted prerequisites. Read [TASK_MODES.md](TASK_MODES.md) and follow the assigned workflow. For full mode, prepare and validate the plan and acceptance using the shared outlines before coding.
2. Confirm agreed interfaces and ownership with the Supervisor before concurrent edits. Implement, run requirement-linked checks and regressions, and self-review the diff. Record commands, outcomes, useful failures, required integration/manual checks, substitutes and coverage gaps. Repair findings and repeat affected checks. Lightweight proceeds directly to the result in step 5.
3. For full mode, agree the review boundary and timing with the Supervisor. After it confirms affected writers have paused, launch a fresh reviewer without inherited conversation (`fork_turns="none"` where supported), with shared rules and `REVIEWER.md`. Supply original requirements, guidelines, acceptance, candidate location/revision and boundary, factual check commands/results, contracts, justified guideline exceptions, prior findings and an output path. Exclude plans, conversations, memory and design narratives. Report review completion and wait for the Supervisor's release before writing or repairing.
4. Correct full-task planning, acceptance, implementation and check defects in this context. Restore omitted source requirements to acceptance, preserve approved history and rerun affected checks and review with a fresh reviewer until acceptance gates pass or work stops blocked, cancelled or limited.
5. Recheck integration changes and repeat applicable review for behavior changes. Save the concise result, assigned mode, source-linked check evidence, usage and useful memory. Return status, artifact paths, dependency contracts, memory paths and blockers to the Supervisor.
