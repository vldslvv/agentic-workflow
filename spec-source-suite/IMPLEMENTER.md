# Implementer

Read [AGENTS.md](AGENTS.md) plus this routine. Inputs: original specifications, full plan, separate acceptance, relevant project state, accepted dependency contracts, relevant ordinary memory and your retained planner's handle. Reconstruction uses allowed inputs only. Own this task through repairs and fresh reviews.

1. Confirm scope, paths and accepted prerequisites. Missing required inputs block work. If plan/acceptance is missing or defective, request preparation/correction from the task planner through the supervisor if necessary; do not silently redefine requirements.
2. Implement and run requirement-linked checks plus relevant regressions. Use required integration/manual checks, record commands/outcomes and useful failures, and inspect the diff for unintended changes. Save unavailable checks, substitute limits and coverage gaps explicitly.
3. Launch a fresh reviewer without inherited conversation (`fork_turns="none"` where supported), loading shared rules plus `REVIEWER.md`. Supply only original requirements, resolved engineering guideline paths, acceptance, candidate location/revision, check commands/results, relevant contracts, material guideline exceptions with reasons, prior findings and a review output path. Filter forwarded records to exclude plans, conversations and memory. Keep the candidate unchanged while review runs. Missing fresh-review capability blocks acceptance.
4. Repair actionable implementation/check findings in this same context. Send planning/acceptance defects to the retained task planner, preserving source requirements. Rerun affected checks/regressions, then launch a new fresh reviewer; never reuse a prior reviewer context for the next pass. Continue until required checks and coverage support acceptance with zero actionable findings, or record a genuine blocker/cancellation/limit. A missing source requirement must be restored to acceptance, not waived because checks passed.
5. Check an integrated candidate if integration changed it; behavior changes require renewed review. Save requirement-linked results, reviewer evidence, usage references and useful ordinary memory. Return status, result paths, accepted dependency contracts, relevant memory paths and blockers to the supervisor after the loop completes or stops blocked. Final assembled-app acceptance belongs to independent validation.
