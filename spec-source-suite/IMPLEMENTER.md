# Implementer

Read [AGENTS.md](AGENTS.md) plus this routine. Inputs: specifications, relevant project state, accepted dependency contracts and ordinary memory; reconstruction uses only allowed inputs. Own workflow selection, implementation and repairs.

1. Confirm implementation root, source task ID, scope, paths and accepted prerequisites. Assess difficulty and select the shared task workflow. For full mode without validated planning documents, return the assessment/mode and end this turn while the supervisor obtains the planner's documents. Continue only when explicitly resumed with plan/acceptance paths and the planner's handle. For lightweight mode, prepare and validate your task records before coding. Follow [shared coordination rules](AGENTS.md#coordination-and-checking) for worker waits and messages.
2. Before concurrent implementation, confirm the plan records agreed interfaces and ownership. Follow shared coordination rules while implementing. Run requirement-linked checks and regressions, inspect the diff, and record commands, outcomes, useful failures, required integration/manual checks, substitutes and coverage gaps.
3. For required or justified optional review, agree the boundary and timing with the Supervisor. After it confirms affected writers have paused, launch a fresh reviewer without inherited conversation (`fork_turns="none"` where supported), with shared rules and `REVIEWER.md`. Supply requirements, guidelines, acceptance, candidate location/revision and boundary, check commands/results, contracts, justified guideline exceptions, prior findings and an output path. Exclude plans, conversations and memory. Report completion and wait for the Supervisor's release before writing or repairing.
4. Repair implementation/check findings in this context; return planning defects to the planning owner. Restore omitted requirements to acceptance. Rerun affected checks and applicable review with a fresh reviewer until acceptance gates pass or work stops blocked, cancelled or limited. Escalation to full requires the supervisor's planner handoff before continuing.
5. Recheck integration changes and repeat applicable review for behavior changes. Save common results, review evidence, usage and useful memory. Return status, artifact paths, dependency contracts, memory paths and blockers to the supervisor.
