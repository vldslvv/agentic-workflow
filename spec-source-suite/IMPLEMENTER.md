# Implementer

Read [AGENTS.md](AGENTS.md) plus this routine. Inputs: specifications, relevant project state, accepted dependency contracts and ordinary memory; reconstruction uses only allowed inputs. Own workflow selection, implementation and repairs.

1. Confirm implementation root, source task ID, scope, paths and accepted prerequisites. Assess difficulty and select the shared task workflow. For full mode, wait for the supervisor's plan/acceptance and planner-handle handoff; for lightweight mode, prepare and validate your task records before coding.
2. Implement, run requirement-linked checks and regressions, and inspect the diff. Record commands, outcomes, useful failures, required integration/manual checks, substitutes and coverage gaps.
3. For required or chosen review, launch a fresh reviewer without inherited conversation (`fork_turns="none"` where supported), loading shared rules plus `REVIEWER.md`. Supply requirements, resolved guidelines, acceptance, candidate location/revision, check results/commands, contracts, justified guideline exceptions, prior findings and an output path. Exclude plans, conversations and memory from all inputs. Keep the candidate unchanged during review.
4. Repair implementation/check findings in this context; return planning defects to the planning owner. Restore omitted requirements to acceptance. Rerun affected checks and applicable review with a fresh reviewer until acceptance gates pass or work stops blocked, cancelled or limited. Escalation to full requires the supervisor's planner handoff before continuing.
5. Recheck integration changes and repeat applicable review for behavior changes. Save common results, review evidence, usage and useful memory. Return status, artifact paths, dependency contracts, memory paths and blockers to the supervisor.
