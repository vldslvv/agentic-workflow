# TODO CLI

Build a simple command-line TODO app for creating, listing, completing and deleting tasks.

- Keep the implementation simple.
- Support parent-child tasks under the [task hierarchy contract](contracts/task_operations.md#task-hierarchy).
- Use uv and `pyproject.toml` for dependency and virtual environment management.
- Use pytest for testing.
- Implement the app at `apps/todolist`, relative to the repository root.
