# Project memory

Apply during ordinary planning and implementation, and when passing memory paths to other workers.

- For ordinary work, read `<project-root>/.agents/memory/index.md`, then only the relevant `entries/*.md`. A missing index means there are no notes yet.
- Treat memory as advice. Follow current requirements and repository facts when they disagree with it.
- Check advice that may be outdated. Do not search unrelated tasks or conversations.
- Save useful lessons when work finishes or is blocked. Include sources that support them.
- Merge duplicate notes and correct outdated advice. Create memory only when there is a useful lesson to save.
- Use ordinary Markdown and short hints that help later workers find relevant notes. No metadata format is required.
- Leave out transcripts, progress logs, guesses, secrets and copied configuration.
- Pass relevant note paths to later workers doing ordinary work. As Supervisor, pass the paths without reading the detailed notes.
- Do not read memory or copies of it as a reviewer, validator or reconstruction worker.
