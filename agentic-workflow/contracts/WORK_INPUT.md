# WorkInput

Supply authorized work and sources for document authoring, implementation, resumption or corrections.

## Fields

| Field | Presence | Meaning |
|---|---|---|
| description | Required | Exact requested work, authorized scope, execution mode, constraints, file ownership, output locations and record location. |
| sources | Required | Paths to governing requirements and relevant existing artifacts. |
| workspace | Required | Authorized project working directory. |

The description identifies fresh execution, unfinished work to resume or findings to address.
Relevant sources include existing Plan, Acceptance, Result and finding paths.
