# DocumentInput

Supply sources and authorized destinations for document authoring or correction.

## Fields

| Field | Presence | Meaning |
|---|---|---|
| assignment | Required | Authorized objective, scope, record location and ownership constraints. |
| sources | Required | Paths to source documents governing the requested work. |
| destinations | Required | Authorized output locations. |
| artifacts | When applicable | Existing specifications, Task order, application Contracts, Verification, Plan, Acceptance, Instructions, Implementation and prior Result paths. |
| memory | Ordinary work only | Permitted index and relevant note paths; omit when absent or excluded. |
